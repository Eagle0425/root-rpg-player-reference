# 新手簡報維護資料

`deck-content.json` 保存 2026-10-24 校訂版的四十五頁內容與來源備註，已同步回工作區原有簡報產製資料。它是導讀節譯，規則案例與設定採原書，不能冒充全書譯本。

`deck-lineage.json` 記錄關鍵規則頁與唯一正文內容雜湊的對應。正文修改後，品質檢查會要求重新檢視相關簡報頁；不自動把舊簡報當成同步完成。更新規則時先比對語義、修正文案，重新產製及檢查版面，再更新這份來源紀錄。

可編輯 PPTX 與可搜尋的投影 PDF 在工作區 `output/簡報/`；原版保留供版本比對，以校訂日期命名的版本為本輪成果。圖片與來源書原件留在工作區，未複製進這份公開維護資料。

# 茂林源記TRPG · Root RPG 玩家手冊

供手機與桌上遊戲查閱的繁體中文靜態網站。

預定網址：**https://eagle0425.github.io/root-rpg-player-reference/**

## 內容

- 9 個基本動作、13 個武器動作、2 個旅行動作、6 個名聲動作。
- 9 項遊俠專長與 8 種風險。
- 45 個裝備標籤（35 正面、10 負面）及 6 件範例裝備。
- 19 種角色、起始技能、天性、動機與角色專屬動作。
- 12 步創角、成長與聚會流程、104 個中英名字、6 種關係。
- GM 目標、原則與動作，以及 NPC／傷害附錄。
- 玩家參考 PDF、列印角色卡、可填寫角色卡。

支援中英全文搜尋、效果關鍵字搜尋、裝備正負面分類、條目永久連結與瀏覽器本機收藏。無登入、無追蹤、無外部字體服務。

## 維護資料

網站直接發布 `site/`，不需安裝套件或建置。

1. 修改 `scripts/reference.json` 中對應的條目。
2. 在儲存庫目錄執行 `node scripts/sync-data.mjs`，同步 `site/data.js`。
3. 執行 `node scripts/validate.mjs` 檢查資料與下載檔案。
4. 推送至 `main`，GitHub Actions 自動更新網站。

PDF 是獨立排版的發行檔，**不會因修改網站資料而自動重新排版**。有規則修訂時，須更新 PDF 後替換 `site/downloads/` 中對應檔案。網頁與 PDF 的當前整理來源均保存在工作區。

## GitHub Pages 設定

本儲存庫包含 `.github/workflows/pages.yml`。首次部署需在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**，然後執行 **Actions → Publish player reference → Run workflow**，或推送一次變更。

使用 GitHub Free 時，採用公開儲存庫。所有網站資源使用相對路徑，可在 `/root-rpg-player-reference/` 下正常運作；路由使用網址片段，不需伺服器重寫。

## 本機預覽

在儲存庫目錄執行：

```text
python -m http.server 8765 --directory site
```

開啟 `http://localhost:8765/`。不連網也能查閱已下載的網站檔案；PDF 下載不會在首頁自動載入。

## 詳細解說（2026.10.19.2）

基本動作 9 項、武器動作 13 項、名聲動作 6 項、旅行動作 2 項、名詞與傷害 8 項，以及裝備建立／買賣，提供可展開的補充解說，共 39 組。解說包含核心規則書印刷頁碼，並納入搜尋；核心規則書版本為 `RootTTPRG_Corebook_100721.pdf`。基本動作另與指定中文網頁交叉核對。

## 閱讀整合（2026.10.19.3）

名字與音譯嵌入創角第 2 步，關係效果嵌入第 12 步，均可展開。裝備建立說明固定置於裝備頁頂端，接續可展開的範例與正負標籤篩選。名詞改為各頁內文的點線連結，開啟定義視窗；仍可搜尋與收藏名詞。舊的名字／關係與名詞目錄連結保留轉址。

四款清松手寫體依原角色卡階層使用，轉為 WOFF2 子集並附原授權，來源與字重見 `site/assets/fonts/sources.json`。新增中文字時應重建字體子集，未收錄字元會使用系統後備字體。PDF 下載內容維持原定稿。

## 首頁與陣營（2026.10.19.4）

網站更名為「茂林源記TRPG」，首頁加入使用者指定的轉載警告、權利文字與遊戲介紹。風險改以文中的點擊視窗查閱，卡片移除制式觸發提示，複製連結改成靠左的文字按鈕。裝備標籤切換保留篩選器在視窗中的位置。

新增八個可搜尋、可直接連結的陣營介紹：貓咪貴族、飛鷹王朝、森林聯盟、茂林居民、河岸商會、陰謀羽黨、鼴鼠地國、蜥蜴神教。核心來源為書內第 21–22 頁；擴充來源為 Travelers & Outsiders 書內第 9–22 頁。各陣營的遊玩切入例為整理者自擬，與來源設定分開標示。後四者中文名稱依使用者指定。字體子集已重建以涵蓋新增文字。


## GM 工作台與陣營圖片（2026.10.19.5）

`gm.html` 是獨立主持人入口，有自己的目錄、資料、全文搜尋、來源／形式篩選、可展開說明、專注閱讀、條目連結與瀏覽器釘選。玩家 `data.js` 不包含 GM 附錄及 NPC 表格；舊 `#gm` 入口自動轉到工作台。這是閱讀分區，不是登入或存取控制。

GM 主資料為 `scripts/gm-reference.json`，共 87 個條目、28 張表。來源包括核心書主持章、戰鬥、NPC、傷害、空地生成與戰爭章，以及 Travelers & Outsiders 的戰役指導、簡易陣營擲骰與利益、進階陣營階段與選用系統。進階階段另分頁定位；貓咪計畫、飛鷹官僚程序已收錄規則與表，其餘陣營先提供扮演與規則定位索引，並未逐項重製所有專屬結果表。工具清單與自擬例子另有標示。

更新任一主資料後執行 `node scripts/sync-data.mjs`，同時輸出玩家 `data.js` 與主持 `gm-data.js`；`validate.mjs` 會核對兩份輸出與表格欄位。玩家／GM 釘選使用不同的瀏覽器儲存鍵。

八個陣營圖片由使用者提供的規則書原始嵌入圖片擷取，保留透明度與原圖內容，另轉 WebP 供網頁顯示。核心印刷頁 21：貓咪貴族與飛鷹王朝；頁 22：森林聯盟與茂林居民。擴充印刷頁 10：河岸商會；頁 13：蜥蜴神教；頁 17：鼴鼠地國；頁 20：陰謀羽黨。原繪 Kyle Ferrin，權利歸 Leder Games／Magpie Games，頁面中標示來源與點擊放大。
